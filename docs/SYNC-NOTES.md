# 公开版同步记录 · 2026-10-25

本轮同步的是已核对的通用修复，不是把私人 Harbour 的工作区或历史整体推送到公开仓库。原 Electron / Web 外观、通用 `main-assistant`、独立数据目录与可自定义开屏继续保留。

## 这次更新

| 范围 | 变化 |
| --- | --- |
| Main Chat | 「＋」在当前窗口创建会话；单独的窗口按钮才新开窗口。旧任务继续执行，结果、停止操作和草稿绑定原会话，不覆盖新会话 |
| 桌面刷新 | F5 / Ctrl+R 的导航中断后会释放刷新锁；保留未保存内容的确认，不自动重放任务 |
| 附件 | 拖入文件、历史图片或浏览器图片与粘贴共用上传路径；远程图片不携带 Harbour 凭据，失败不会伪造附件 |
| 历史图片 | 压缩后保留经过验证的主人图片定位元数据；仍需通过 `view_image` 权限读取，不自动授予上传权限，到期清理不刷新保留时间 |
| Claude API | 官方 API 的模型发现使用正确请求头，保留自定义名称和启用选择；官方端点使用原生 effort，兼容供应商保留原 token 预算行为 |
| 浏览器基础层 | 更新图片站点的 token 计数定位与准备失败诊断；未知页面仍停止，不重放生成、不泄漏 Prompt |
| README 与视频 | 删除重复短版入口，整理安装与 Agent 交接；增加真正的独立播放器、下载、失败提示和复制安装 Prompt |

## 不随本轮同步的内容

- 私人 Agent、人设、偏好、记忆、附件、日志、会话、密钥与账号绑定。
- 私人 Skill / Workflow / MCP、图片提示词模板、模型文件和素材包。
- claude.ai 订阅登录。公开版的 Claude 连接使用用户自己的 Console API Key。
- 来源工作区中仍在开发、尚未完成验证的模型路由重构。

未附送的能力包仍按原公开版规则关闭；源码中的兼容字段不是已经安装这些能力的承诺。模型默认值和用户自己的配置不会因本次同步被替换。

## 验证方式

以下命令均使用离线 fixture、模拟服务或隐藏测试窗口，不调用真实模型、不提交生图：

```powershell
npm run test:public
npm run test:chat-sessions-ui
npm run test:desktop-refresh
npm run test:chat-drop
npm run test:showcase
```

另检查了会话浏览、断线恢复与模型切换回归。`test:public-runtime` 覆盖历史图片的身份隔离、压缩和保留期、API 认证头/effort、浏览器计数与失败不重放。外部服务的真实生成不属于本次验证。

发布前执行 `npm run audit:public`，再人工审核 staged 文件与公开仓库历史。模式扫描不能代替完整安全审核或素材版权审核。

## 视频如何发布和维护

GitHub README 的 MP4 文件链接不是可靠的嵌入播放器。现在 README 只保留一张预览图，点击进入 [产品介绍页](https://demonrain7.github.io/harbour-lite/)。

- GitHub Pages 来源：`main` 分支的 `/docs`，`.nojekyll` 禁用转换；只发布已有公开文档和素材，不运行 Harbour 后端。
- 页面与 MP4 同源；相对路径兼容 `/harbour-lite/` 子路径。原生播放器支持声音、进度和全屏，不自动播放。
- 本轮复用已有的 78 秒 H.264 / AAC 介绍片，没有重新生成视频。影片含模拟任务与历史制作文案，以当前 README 的安装和发布说明为准。
- 加载失败有重试、下载和原始文件备用入口。GitHub Pages 不保证在所有网络下均可访问；安装信息独立于视频。
- `npm run test:showcase` 验证本地真实视频解码、播放、跳转到 39 / 75 秒、窄屏、复制失败和视频 404 恢复。
- 部署后执行 `npm run test:showcase -- --live`，直接验证上述公开 URL 的实际媒体加载和播放，而非只检查链接状态。

更新页面不需要重新构建应用。重新制作影片时请同时更新海报、片长、制作说明和测试预期，并再次审核可见信息。
