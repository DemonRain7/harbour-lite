# 公开副本清单

本副本沿用原 Harbour 的 Electron / Web 实现，不是另写一个精简客户端。公开版使用独立 Git 仓库，在功能分支审核后合并到 `main`，不推送私人仓库的历史。本轮更新见 [同步记录](SYNC-NOTES.md)。

## 保留

- 原主题、字体、布局、聊天框、侧栏、设置页与开屏动画。
- Agent、模型、工具、权限、Skill / Workflow / MCP、会话与调度框架。
- 桌面窗口、音乐 / 语音、悬浮助手等通用实现；具体账号和资源由使用者配置。
- 通用字体、图标、带许可的第三方源码，以及与私人提示词分离的普通角色装饰图；素材权利说明见下文。
- 两个通用示例 Skill：清晰写作、任务规划。默认 Agent 不自动挂载额外权限。

## 不随副本带出

- 原 `.env`、模型配置、密钥、登录、QQ / Discord 绑定与第三方账号。
- 主人档案、偏好、私有角色规则、记忆、聊天、Trace、checkpoint、上传和报表。
- 私有 Skill / Workflow / MCP 包、NSFW 提示词、个人定时作业。
- 本机下载的语音模型、Live2D / 3D 模型、音乐、表情包。
- 原仓库 `.git` 和个人提交历史。

私有能力包未安装时不注册其执行器；通用扩展接口保留。源码中兼容旧任务格式的字段，不代表附带私人素材或开通该能力。

## 普通图片

本机保留 `web/assets/` 的两张头像、五张主题立绘及原有 SVG 装饰，开屏保留两张普通着装角色图。清除了七张图片中的 PNG 文本 / EXIF / JPEG 描述块；解码后的像素逐字节对比一致，没有重新绘制或改变画风。此检查不代替素材的版权审核。

## 验证范围

- `test:public`：类型检查、公开版配置隔离、开屏与安装交接、聊天与模型选择回归，以及本轮运行时测试。
- 隐藏 Electron / Chromium：真实同页新会话、多任务隔离、F5 中断恢复、未保存确认与附件拖放。测试不连接私人服务。
- `test:showcase`：已有 78 秒 MP4 的真实解码、播放、进度跳转、窄屏布局、复制与加载失败恢复。
- `audit:public`：导出路径、常见凭据模式与图片元数据；该检查不构成完整安全或版权审计。

具体命令、同步范围和未验证的外部服务见 [同步记录](SYNC-NOTES.md)。产品介绍片是公开界面与模拟任务的展示，不等于外部服务功能验收录屏。

## 隔离

预览只监听 `127.0.0.1:7799`，默认演示模型且无服务密钥。运行数据位于本副本的 `data/`；桌面应用使用 `HarbourPublic` 独立目录。旧目录迁移默认关闭，Live2D 不自动下载。开屏自定义图片只读取用户指定的本机文件。

宣传片另用被忽略的 `.local/` 临时 Harbour 实例，按本次用户要求显式调用 GPT-6 Astra（Max），不改变上述预览配置。临时 Agent、官方 Remotion Skill 副本、登录与原始 Trace 不随 Git 分发；仅发布白名单制作摘要和视频源码，见 `demo/HARBOUR-RUN.json`。

## 发布边界

以公开仓库 `main` 的源码与 README 为准；本轮没有重新制作安装包，历史 Lite 安装包不代表当前版本。代码与素材按实际待提交文件审核；普通角色图不等于已取得所有公开分发权。Folia 的 AGPL-3.0、字体 / 图标许可、Remotion 条款与角色素材权利不能用统一 MIT 声明覆盖。
