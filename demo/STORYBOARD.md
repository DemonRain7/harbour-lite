# Harbour — 把熟悉的外壳，交给你自己的 Agent

## 本轮创作与素材边界

全新叙事与场景实现，不重导上一版。沿用现有 demo、Remotion 4.0.537、Noto Sans SC 和仓库已有 Harbour 手写字标字体，不新增依赖或下载素材。仅使用授权公开截图 `public/original-main-chat.png`（2360×1371），以及 README / docs/AGENT-SETUP.md 的产品事实。未读取私人项目、环境文件、会话或历史。片中截图不是当前实时录屏；关系图和对话缩写均另行标明。

固定交付：HarbourIntro / 1920×1080 / 30 fps / 900 帧 / 30 秒 / H.264 MP4，无音乐、无 TTS、无音轨。只能通过限定 promo_build 导出到 `../docs/media/intro-harbour.mp4`；不改旧 intro.mp4、README 或脚本。

## 视觉方向

奶油纸 #FAF3E6、紫藤墨 #4A3F5C、薰衣草 #8A70E0；保留原 Electron / Web 的精致手账气质。大字、宽留白、少量手绘星芒与纸胶带；真实 UI 负责产品形象，不重画一个精简客户端。以摄影式 UI 镜头、能力关系图、单张交接便笺形成不同构图。禁止密集卡片、伪造安装成功、密钥或个人内容。

轻量帧驱动动画：短距离入场、缓慢镜头推进、SVG 连线描绘。场间 15 帧纸色过渡，前半退出、后半进入，避免标题重影；不使用 GPU-heavy 后处理。结尾保持可读，不黑场淡出。

## 本轮验证计划与限制

1. TypeScript check 成功后，stills 渲染六张关键帧。
2. 用 view_image 逐张查看源截图与六张实际 still；按视觉结果修正再构建。
3. render 新 MP4；decode 执行 ffprobe、全片解码及最终 MP4 抽帧。
4. 至少实际查看两张最终 MP4 解码帧；不把独立 still 当成最终 MP4 验证。
5. 本轮 view_image 工具调用最多 10 张预算。源截图像素已检查；其余用于六张 still 和两张 decoded。

Studio 由本任务在独立端口启动，本轮 Harbour 导演无 Browser Controller，不声称它完成了浏览器/Studio 可视验收。导演仅验证视频文件与实际输出帧，不测试 Harbour 产品安装、模型连接或完整功能。README 与交接文档中的命令仅作资料，不在导演运行内执行；外层整合与独立复核见 VIDEO-NOTES.md。
